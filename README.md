# The-Tech-Academy-Basic-C-Sharp-Projects
## Description

This repository contains my projects and exercises completed during a C# and .NET course. It showcases practical applications of core concepts like object-oriented programming, web development with ASP.NET MVC, and database integration using Entity Framework.

## Projects Completed

### 🚗 Car Insurance Quote Application
A full-stack web application designed to simulate a real-world insurance quoting system.
* **Key Features:** User input form handling, automated business logic to calculate risk/quotes, and an admin view to track issued quotes.
* **Tech Used:** C#, ASP.NET MVC, Entity Framework, SQL Server.

### 🧮 Core C# & OOP Exercises
A collection of console applications demonstrating foundational programming principles.
* **Key Features:** Examples of encapsulation, inheritance, polymorphism, and interfaces.
* **Tech Used:** C#, .NET Framework.


## Features
- **Object-Oriented Programming (OOP):** Encapsulation, inheritance, polymorphism, and interfaces.
- **Web Development:** Building multi-page applications using ASP.NET MVC.
- **Full-Stack Development:** Form handling, CRUD operations, business logic implementation, and SQL Server integration.

## Technologies Used
* C#
* .NET Framework
* ASP.NET MVC
* Entity Framework
* SQL Server
